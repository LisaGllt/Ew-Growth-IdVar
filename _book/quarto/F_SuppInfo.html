7.3 Comparison with a frequentist approach

7.3.1 Frequentist LMMs using glmmTMB

Close replicates of our bayesian models were made using a frequentist approach with glmmTMB (Brooks et al., 2017).

Code 
# Model with no effect between cohorts
glmmTMB.null = glmmTMB(
  L ~ t , 
  df_growth
  )
# Model with the effect of the pesticide only
glmmTMB.trt <-  glmmTMB(
  L ~ exposition * t, 
  df_growth
  )
# Model with only inter-individual variation
glmmTMB.vi <-  glmmTMB(
  L ~  t + (t|ID),

## Checking priors sensitivity {#sec-Fpriorsens}

#| code-fold: show

# Model with no effect between cohorts
glmmTMB.null = glmmTMB(
  L ~ t , 
  df_growth
  )
# Model with the effect of the pesticide only
glmmTMB.trt <-  glmmTMB(
  L ~ exposition * t, 
  df_growth
  )
# Model with only inter-individual variation
glmmTMB.vi <-  glmmTMB(

  df_growth
